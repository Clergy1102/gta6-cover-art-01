Vice City Cover Lab turns your own photos and a caption into multi-panel GTA-style cover art — four layouts, three sunset/neon colour grades, drag-to-reframe tiles — and exports a share-ready PNG. It runs fully offline in the browser; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
